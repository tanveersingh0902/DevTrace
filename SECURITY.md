# Security policy

DevTrace is in development. Include the affected commit or branch in a report so maintainers can identify the relevant code and migrations.

## Report a suspected vulnerability privately

1. Open the repository's **Security** tab and select **Report a vulnerability** if available. The form sends the report privately to maintainers. [GitHub private reporting guide](https://docs.github.com/en/code-security/how-tos/report-and-fix-vulnerabilities/report-privately)
2. If the button is unavailable, use a private contact method a maintainer lists on their GitHub profile. If none is listed, open a blank issue asking only for a private reporting channel. Withhold all technical details until a private channel is available.
3. In private, include the affected component, commit, impact, and a minimal description of what you observed. Remove passwords, tokens, personal data, and private source code from examples and logs.

Keep details and proposed patches out of public issues, discussions, and pull requests while maintainers assess the report. Coordinate a fix and disclosure timing in the private thread.
